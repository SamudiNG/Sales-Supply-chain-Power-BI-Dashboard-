# Sales & Supply Chain Performance Dashboard

##  Project Overview

This project presents an interactive Power BI dashboard designed to analyze sales and supply chain performance. The dashboard provides insights into sales, profitability, order performance, shipping efficiency and product returns to support data driven decision making.

##  Key KPIs

- Total Sales - 2.30M
- Total Profit - 286.40K
- Total Quantity - 38K
- Total Orders - 5K
- Average Shipping Days - 34.61
- Returned Orders - 296
- Return Rate - 5.91%
- On-Time Shipping Rate - 61.99%
- Late Orders - 2K

##  Dashboard Analysis

The dashboard includes analysis of,

- Monthly sales trends
- Sales and profit by product category
- Sales performance by region
- Top 10 products by sales
- Average shipping days by shipping mode
- Returned orders by category
- Return rate by category
- On-time and late shipping performance

##  Key Insights

- Technology generated the highest sales among the product categories.
- Technology also produced the highest profit.
- The West region recorded the highest sales performance.
- Office Supplies had the highest number of returned orders.
- Technology showed the highest return rate among the analyzed categories.
- Shipping performance indicates opportunities to improve on-time delivery.
